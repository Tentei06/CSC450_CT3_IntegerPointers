# CSC450 Module 3 Critical Thinking – Integer Pointers

A C++ console application demonstrating the use of integer pointers and dynamic memory allocation.

## Overview

This project was created for the Module 3 Critical Thinking assignment in CSC450 – Programming III at CSU Global.

The program demonstrates basic pointer and memory management concepts in C++. It accepts three integer values from the user, stores the values using dynamically allocated memory, displays the integer and pointer information, and releases the allocated memory when it is no longer needed.

## Features

- Accepts three integer values from the user
- Uses integer pointers
- Allocates dynamic memory using the `new` operator
- Displays integer values and pointer information
- Deallocates dynamic memory using the `delete` operator
- Demonstrates basic C++ memory management
